# FAZZ 头部建模

把参考中的外轮廓、体积、部件接合和遮挡关系转成可编辑的三维头部。先纠正形体，再增加细节。范围跟随用户当前要求；只做头部时，不顺带制作身体或改动全身骨架。

这套方法来自一次反复返工的 Blender 建模。实际使用 Python 创建和修改网格，通过 MCP 执行、渲染和检查；并非用雕刻笔刷逐笔雕出。本 skill 总结可复用的方法及失败经验，不把当时尚未完全还原的模型当成正确答案。

- 继续原 FAZZ 文件或查询“当时怎么做的”：读 [本次构造与项目记录](references/fazz-head-case.md)。
- 执行 Blender 脚本、固定视角检查或处理导出问题：读 [执行与验证](references/blender-review.md)。
- 自动生成检查图与几何记录：使用 [review_head.py](scripts/review_head.py)。它不生成头部，也不判断造型是否像参考。

## 1. 确认参考与现有资产

读取用户最后指定的主参考，以及当前实际使用的 `.blend`。检查头部对象、隐藏集合、父级、材质和相机，避免改到旧版头或其他资产。开始编辑前保存工作副本。

主参考决定外形。说明书适合确认部件结构，其他实拍适合补充侧后方信息；遇到不同版本或相互冲突的造型，不平均混合。记录哪些细节有图可证、哪些由遮挡后的形体推断。

原案例使用最后提供的 **MG FAZZ Ver.Ka 宣传图**；最早的 AI 四视图已被替代。辅助对比实拍采用左侧 Ver.Ka 头，不采用右侧旧版头。不要把这个左右规则推广到别的图片。

## 2. 建立比例和观察基准

先看不含天线的头盔宽、高、深，再看额头、面罩与眼区所占比例。记录中轴、头顶、下巴、颧侧最宽处、眼内外角、额头上下端、天线根与尖端等可辨认的点。

在同一视角内以头盔宽度或高度归一化测量。照片有透视时先匹配相机方向和透视；不能直接用正交模型图的像素比判定照片里的尺寸。看不清的尺寸给出估计与依据，不编造原厂数据。

坐标约定可用 X 左右、Z 向上、前方 -Y；已有项目使用其他约定时保持一致。头部外形按参考建立，骨架通过安装根与颈部接口适配，先检查是否存在真实的空间冲突，再判断骨架是否限制造型。

建立固定的正面、侧面、前方斜视、后方斜视相机；补充低角度和底部视图来发现遮挡、穿插与露底。后续对比沿用相同相机、构图、灯光、曝光和材质。

## 3. 按形体关系构造

先用低复杂度网格建立头盔、前倾额头、面部和天线的大轮廓，从正面与侧面同时校准。比例还没站住时，先修主要形体，不用倒角、刻线或发光掩饰。

| 部位 | 构造方式 | 关键检查 |
| --- | --- | --- |
| 头盔与眉缘 | 沿前后方向布置轮廓截面，连接成面，补足侧壁与回折面；眉缘独立控制 | 前额两侧是否漏出意外黑洞；侧面层次是否连续 |
| 紫色额头 | 分出顶面、侧壁、前框、内唇和深色凹入件 | 必须有前倾体积与前后深度，不能只是一张厚平板 |
| 眼区 | 深色眼眶、凹入镜片、上眉缘/额头遮挡分开控制 | 对照实际可见的眼形与神态，不能只看镜片尺寸 |
| 面罩与下巴 | 窄面罩、中央折面、真实凹槽、独立下巴折面 | 面罩与额头/颊部的比例，凹槽是否藏在表面内 |
| 颊部与侧面 | 用相接的截面构成主体，凹口有口沿、内壁、底部 | 不能靠悬空的多层贴片假装结构复杂 |
| 四片天线 | 从正面轮廓建立有厚度的板状网格，分别处理根部和尖端 | 展开角、长短、根部厚度，以及侧面的倾斜 |
| 后脑 | 壳体包络、贴合的中央脊、格栅框、实体栅片、观察窗 | 中央脊应贴合头盔，避免变成镂空提手 |

左右先镜像共用形体，再处理参考中确实存在的不对称。前后深度必须用侧视/斜视验证；正面轮廓相似不意味着三维结构正确。

## 4. 落实厚度、凹槽和接合

截面连接、显式封边和按法线加厚通常比全头体素重网格更能保留硬表面转折。给真正的壳体使用 Solidify；复杂脊条或格栅可直接建立封闭截面。不要把固定轴挤出误认为沿表面法线加厚。

真实开孔可使用布尔差集，口沿与深色内衬保留为单独部件。每做一处先检查穿透方向、剩余壁厚与两侧外观，再处理下一处。清理本次创建的临时切割物体，不按宽泛名称批量删除场景物体。

倒角以该部件最窄处、槽宽和面转折为依据。细窄面需要更小的倒角；不要用一套全局宽度把所有折面磨圆。法线修正服务于清晰的面，不能替代错误几何的修复。

## 5. 反复对照与局部迭代

按“轮廓和比例 → 接合与遮挡 → 凹槽和倒角 → 材质”检查。每轮选一个明确问题，保存修改前图，调整相关部件，重新渲染受影响的视角。没有改善就回到结构或参考解释，不无限缩放同一块网格。

眼睛偏小时，分别检查：镜片本体宽高、眉缘遮住多少、额头或天线根挡住多少、镜片深度、相机角度。可见面积改变不等于镜片等比放大。增大发光强度不会修好眼形；把镜片推到最前面又可能让低角度出现悬空绿条。

原案例提出过“可见高度试增 10%–15%、宽度少动”的下一轮方案，**当时尚未实施和验证**。这是该版本的试调起点，不是 FAZZ 的标准比例。继续修改时应重新与主参考比较。

## 6. 保存、复开与交付

保留适合继续编辑的源文件。若交付版本需要实现修改器，在副本中进行，保留各部件可编辑性；不要把烘焙修改器当成每次保存的必需步骤。把头部与预览灯光分组，保留安装根并记录前轴与原场景变换。

保存后重新打开**交付文件**生成最终检查图。分别记录：

- 外形检查：主要比例、各方向轮廓、眼区可见形状、接合、参考不确定处和剩余误差。
- 几何检查：无效坐标、退化面、边界/非流形边、明显对称偏差、临时对象。根据部件用途解释开放边界。
- 文件检查：头部身份、对象分组、引用图片可用性、安装信息；文件可打开与 GUI 已正常显示是两个事实。

几何无报错不代表外形准确，也不代表多个独立壳体已成为可打印实体。用模型的实际渲染作为证据，明确仍需修正之处；只有实际完成的检查才能写入交付说明。
